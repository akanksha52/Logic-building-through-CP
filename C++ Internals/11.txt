Size: The number of elements currently stored in the container.

Capacity: The total number of elements the container can store in its currently allocated memory without requiring a reallocation.

resize changes the size of the container to n elements. If the new size is larger, new elements are added; if smaller, elements are removed.

reserve ensures that the container has a capacity of at least n elements, without changing its size.

reserve() is mainly used to avoid repeated memory reallocations and copying/moving of elements when you know the vector will need a certain amount of space.

push_back() adds an existing object/value to the end of the vector by copying or moving it into the vector.

emplace_back() constructs a new object directly at the end of the vector using the arguments provided. It can avoid creating a temporary object before putting it into the vector.

In push_back():
    Person p
    ↓
    copy/move
    ↓
    vector

In emplace_back():
    "Silky"
    ↓
    Person constructed directly inside vector

emplace_back() is not always faster. With modern C++, the difference can be small or nonexistent in many cases, especially when already passing an rvalue to push_back().

Reallocation can make iterators invalid like v.begin() for already seen reason.
