CMake is a tool that describes how your C++ project should be built. CMake creates the instruction for building the project.

Commands generated by cmake are managed by build systems.

We will have a file called CMakeLists.txt is basically the instruction sheet for cmake.

CMake supports multiple build systems, a generator is simply the type of build system that CMake will generate.

cmake -G Ninja: Generate Ninja build files.

cmake -S <dir>: dir is the project in subject.

cmake -B <dir> the directory where we wish to keep our build files.

cmake --build build: Actually build the project.

cmake -G Ninja -B build

There are different build configuration debug, Release et we use for different purpose.

Single-config: Choose the build typewhen configuring cmake.
Command is: cmake -S . -B build -DCMAKE_BUILD_TYPE=debug

Multi-config: Several configuration available in the same build directory then while building we choose the one when building.
Coomand is: cmake --build build --comfig Debug.

To run the executable: .\build\Debug\1.exe
